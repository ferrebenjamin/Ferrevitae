## 🚀 Cómo publicar en GitHub Pages

1. Creá un repositorio público en GitHub llamado `cv-portfolio-web`.
2. Subí estos tres archivos (`index.html`, `style.css`, `script.js`) a la raíz del repositorio.
3. Andá a **Settings → Pages**.
4. En "Source" elegí la rama `main` y la carpeta `/ (root)`.
5. Guardá y esperá unos minutos: tu sitio va a quedar publicado en
   `https://ferrebenjamin.github.io/cv-portfolio-web/`.
6. Actualizá el enlace de la sección "Demo en vivo" de este README con esa URL.
